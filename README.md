# Lawrensvic M. Arangel — Personal Portfolio

## Files
- `index.html` — GitHub Pages entry point.
- `portfolio.css` — responsive portfolio styling inspired by the supplied `home.css`.
- `portfolio.js` — mobile navigation behavior.
- `assets/places/` — optional folder for the original destination images.

## Add your original images
Copy these original files into `assets/places/` if you want the destination cards to use the same images:
- `shibuyaJP.jpg`
- `chinatownTH.jpg`
- `seoulK.jpg`
- `sanfranciscoC.jpg`

The portfolio works without those images; the cards fall back to a purple gradient.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `lawrensvic-portfolio`.
2. Upload `index.html`, `portfolio.css`, `portfolio.js`, and the `assets` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL.

The site is plain HTML/CSS/JavaScript, so no Node.js, npm, or build process is required.
